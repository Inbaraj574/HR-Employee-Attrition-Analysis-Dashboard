# HR Employee Attrition Analysis Dashboard
# Tools: Excel | Dataset: IBM HR Analytics | Records: 1,470

## Project Overview
Analyzed IBM HR Analytics dataset to identify key 
factors driving employee attrition using Microsoft Excel.

## Dashboard Features
- 4 KPI Cards — Total Employees, Attrition Rate,
  Avg Salary, Avg Age
- Attrition by Department (Bar Chart)
- Attrition Yes vs No (Pie Chart)
- Avg Salary by Job Role (Bar Chart)
- Attrition by Age Group (Bar Chart)
- Interactive Slicers — Department, Gender, Age Group

## Excel Skills Used
- Data Cleaning — Remove duplicates, blank checks
- Pivot Tables — 5 pivot analyses
- Formulas — VLOOKUP, INDEX MATCH, IFS, COUNTIF
- Dashboard — Charts, Slicers, KPI Cards

## Key Insights
1. R&D department has highest attrition (133 employees)
2. Employees aged 26-35 leave the most
3. Low work life balance increases attrition rate
4. Employees with no stock options leave more
5. Junior level employees have highest attrition
